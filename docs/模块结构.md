## 一句话

原来 `src/` 是几个上千行的大文件（`lib.rs` 567、`parser.rs` 1610、`compiler.rs` 1974、`jit.rs` 1985、`vm.rs` 1346）。
现在按**编译流水线的阶段**分层，`lib.rs` 只剩模块声明与 re-export。

## 为什么这么分

| 层 | 判据 |
|---|---|
| `classfile` | 只依赖 std，任何东西都能用它读写 `.class`（`roundtrip_dir` 靠它验证 33191 个 JDK class） |
| `front` | 不依赖后端；parser 里没有任何类型检查 |
| `sema` | 只读 AST，产物是符号表与引用位图（GC 的 `ClassMeta` 从这里来） |
| `codegen` | 只产出 `ClassFile`，不执行任何东西 |
| `vm` / `jit` | 两个独立执行引擎，共享 `classfile` 的类模型，互不依赖 |

## 旧路径兼容

`lib.rs` 用 `pub use` 保住全部旧路径，`examples/` 一行未改：

```
classfile::parse / write / Error / Result
classfile::ast / lexer / parser            ← front 的 re-export
classfile::compiler::*                     ← codegen 的别名
classfile::codegen::*                      ← codegen 本身
classfile::vm::* / classfile::jit::*
```
